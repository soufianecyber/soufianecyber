### 🎯 What It Does

QSM addresses the **"Harvest Now, Decrypt Later" (HNDL)** threat by:

- 🔍 **Auditing** existing cryptographic assets (RSA, ECC, DSA) in TLS and SSH keys
- ⚛️ **Simulating** Shor's Algorithm attacks with realistic qubit/time estimates
- 🔄 **Migrating** Nginx and OpenSSH configs to **hybrid post-quantum cryptography**
- 🛡️ **Enforcing** a strict hybrid invariant — pure PQC is architecturally forbidden
- ↩️ **Rolling back** atomically with SHA-256 checksum-verified backups
